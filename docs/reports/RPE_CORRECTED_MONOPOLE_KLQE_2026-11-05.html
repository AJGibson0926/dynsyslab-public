From corrected echo to a state estimate: joint HDMD and KLQE

← Corrected echo and fitted dynamics

Can an estimator driven only by corrected acoustic echo recover radius and velocity? We separate two tests: decoding x and e from a reference Ψ obtained from a joint measurement window, and estimating Ψ online with only echo. Success in the first test does not imply success in the second.

Construction and comparison protocol

Reuse the same unforced high-resolution RPE training record and physical parameters. Form end-aligned joint windows of radius and corrected intrinsic echo, with 12,751 samples per channel, raw channel scales (1,1), stride 245 between window starts and a one-sample DMD step, Δτ = 0.0001. The snapshot matrix has 25,502 rows and 3,200 columns. Retain fitted Koopman rates, the echo reconstruction Cᵧ, and the state decoder Cₓ for (r,v). Radius and echo enter the joint fit; velocity is an additional fitted reconstruction channel. A reference Ψ is a modal projection of a joint training window, not a known exact eigenfunction. The three rank limits are separate fits.

Start each continuous-time KLQE from zero lifted coordinates. It receives only e, uses the original retained Cᵧ for its innovation, and returns x̂ = CₓΨ̂. For the clean measurement test the measurement covariance floor is 10⁻¹⁰; Q = 10⁻⁴I. For the noisy test, the sensor standard deviation is 1% of the corrected training-endpoint echo standard deviation; measurement covariance is max(10⁻¹⁰,σ²Δτ). The truth state is used for scoring. Original ranking, realization tolerances and controller/estimator software are unchanged.

Selection and observability

Keep conjugate pairs together, normalize coordinates by their training RMS, scale state outputs, and whiten echo by the sensor noise. First discard unpaired negative-frequency representatives, modes outside −50 ≤ Re(λ) ≤ 0.01 or with |Im(λ)| > 1000, and normalized endpoint propagation defects ≥ 0.5. For each ranked proposal the native assessment adds state truncation error, measurement reconstruction error, state-weighted posterior uncertainty and a dynamics-defect penalty. The full large-bank Gramian uses T = 0.001 because growing rates make long horizons unreliable; candidate information tests use T = 2. The Gramian singular vectors mix modes; the candidate selection retains identifiable eigenfunction columns. A numerical rank is not a guarantee of practical signal-to-noise or correct dynamics.

For the full 3,167-mode bank, the short-horizon (T=0.001) numerical observability rank was 3. The first four singular values of the observation map were 4615.17, 22.1753, 0.122137, 0.00107268; cutoff 0.00146162. This is an effective rank at a particular time horizon, scaling and threshold in unconstrained complex modal coordinates, not a proof of exact unobservability at longer horizons.

The full 80-mode realization is reported numerically rank 80, but the largest/smallest Gramian eigenvalue ratio is 1.26255e+16 (range 4.57859e-05 to 5.7807e+11). This is near the limit of double precision. Calling all directions observable does not mean all of them are measurable at useful precision. Its normalized propagation penalty is 0.893714.

The three large-bank subset observers failed. Across the three clean runs, radius RMSE is about 1.20 and echo relative RMS is 99.6–99.9% of the zero-echo predictor. The full bank reconstructs the training endpoints extremely well, but the selected columns on reference Ψ already give normalized echo reconstruction MSE near 1. That loss precedes feedback. In contrast, the full 80-mode observer tracks clean echo much more closely but still misses the absolute radius.

For a follow-up, test an explicit equilibrium offset using deviations (r−1,v,e−e₀), score the decoder on separate trajectories before designing gains, and require retained modes to preserve the complete measured waveform as well as state. Report the equilibrium baseline and late-time bias. These are diagnostic next steps; none was introduced into this reproduction, and centering alone would not establish a usable observer.

On held-out data, echo RMSE is 0.000535153 but radius RMSE is 0.993541. As the physical bubble approaches r = 1, the echo approaches zero; matching that small measurement does not anchor the absolute radius in this uncentered modal observer. See the late-time radius error and the time traces. The correction changes the sensor but is not a solution to lifted-state estimation.
