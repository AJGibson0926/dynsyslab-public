Why echo-history KLQR is not yet reliable

Recommendation: stop broad gain sweeps and validate the lifted dynamics before asking KLQR to control them. The main obstacle is not simply a bad numerical solve or an insufficient number of sine bursts. The present fit confounds autonomous/history drift with current-input response. A second, independent limitation is that the controller has no nominal forcing term for persistent periodic tracking. The current frozen models cannot support a claim of reliable nonlinear control.

The primary pipeline was left unchanged. One isolated C++ audit executable reused existing projection, polynomial, integration, least-squares, archive and LQR components. A small presentation script assembled these results using native Viewer. No new SVD, eigenfunction training, controller architecture or primary-pipeline edits were made. An isolated diagnostic refit used the existing bilinear regression routine; it was not installed or used for closed-loop control.

1. What was kept fixed, and what was tested

The system remains the viscous air-in-water RPE bubble: equilibrium radius 10 μm, ambient pressure 100 kPa, viscosity 0.001 Pa·s, density 998 kg/m³, surface tension 0.0725 N/m, polytropic exponent 4/3 and vapor pressure 2330 Pa. The synthetic sensor is the intrinsic, zero-input-convention far-field echo. Driver scattering and direct acoustic feedthrough remain intentionally excluded. These are noiseless simulation tests, not laboratory validation.

Sensor spacing is 0.0005 τ; inputs are held for h = 0.01 τ. The old long history contains 8644 samples spanning 4.3215 τ; the short history contains 101 samples spanning 0.05 τ. Each stored U has four columns. The tested polynomials use either the first two or all four latent coordinates, but each model produces one complex eigenfunction—two real feedback coordinates.

2. Implementation checks: what is not the main problem

  • Offline FFT-based projection and online ring-buffer projection agree to relative L² error below 2.9 × 10⁻¹⁵ on the sampled windows. Both use oldest-to-newest history ordering and the same U / singular-value normalization. Maximum absolute discrepancy is below 4.6 × 10⁻¹⁷.
  • The integrator stores the newly selected input at each tick; that is the input driving the following interval. The regression uses that same interval-start input. The target indexing in the feedback loop is aligned to the completed history endpoint, not its midpoint.
  • Replaying the recorded input in the probe acquisition adapter reproduced the stored echo exactly in this run (relative discrepancy zero). Halving/doubling the probe amplitude changed the central input sensitivity by less than 1.2 × 10⁻⁶ in relative L² across these cases.
  • The existing algebraic regression test verifies exact recovery for synthetic data generated by the assumed bilinear model. That test passes, but it does not establish that this bubble/history representation actually obeys that model.
  • The sampled experiment calls the existing continuous-time Riccati solver every hold and applies u = −K error. It is an isolated sampled adapter, not a claim that the production continuous-RHS controller has become a discrete-time LQR.

There is no evidence here of a projector-order, target-time or simple input-recording error causing the scientific failure. This does not certify every implementation detail, nor eliminate laboratory timing/noise issues.

3. The decisive experiment: change only the next input

Let z = ψ(ξ), μ = exp(λh). The existing fit assumes:

qₖ = zₖ₊₁ − μzₖ ≈ B̂d(zₖ)uₖ,
B̂d(z) = c₀ + c₁ Re(z) + c₂ Im(z).

At each probe point, the complete echo prehistory was held identical. The acquisition adapter then continued the plant for one hold with u = 0, ±δ, ±2δ, ±δ/2, and the recorded input. Here δ = 0.01 for the mild case and 0.1 for the nonlinear case. Only echo histories, echo continuations, time and input were passed into the diagnostic calculations. Simulator states stayed inside acquisition.

aₖ = zₖ₊₁(0) − μzₖ,
Bcausal(Hₖ) ≈ [zₖ₊₁(+δ) − zₖ₊₁(−δ)] / (2δ),
zₖ₊₁(u) − μzₖ = aₖ + Bcausal(Hₖ)u + higher-order input terms.

aₖ does not vanish on these forced histories. No choice of a finite B can repair that discrepancy at u = 0. The old regression tries to put this residual into B because current input is correlated with the past driven motion.

For the simplest constant-B illustration, if q = a + Bu, least squares through the origin gives B̂ = B + E[u a] / E[u²]. A periodic input and its driven history can make E[u a] nonzero. More samples of the same correlated experiment need not remove this bias. The actual bilinear regression has the same omitted-drift issue with a larger feature matrix.

5. Why a free-trained history coordinate is not automatically a state coordinate under forcing

The causal coordinate is a linear filter of a whole measured history:

Hₖ = [eₖ₋d₊₁, …, eₖ]ᵀ,
ξⱼ,ₖ = Σℓ=0…d−1 Uℓj eₖ₋d₊₁₊ℓ / σⱼ,
zₖ = ψ(ξ₁,ₖ, …, ξᵣ,ₖ).

Along an autonomous free trajectory, its history is tied to the autonomous flow. Training ψ there constrains its evolution on that collection of histories. Under arbitrary forcing, the same current physical state can have different past echoes because different past inputs brought it there. The stored history, and therefore ξ, need not be a function of current (r, ṙ) alone. A polynomial that is approximately an eigenfunction on free histories need not retain the same autonomous evolution on forced histories.

This is the important correction to the earlier idea that only the coordinate transform changes and everything after it is identical. The polynomial data classes and evaluators can remain identical. The dynamical closure assumption cannot simply be carried across. A causal input derivative on the full history state can exist without the identity ż = λz + B(z)u being valid.

Over one control hold, only 20 newly measured samples enter the buffer. The long window retains most of its 8644 samples. That does not itself quantify delay or authority—the weights and observable matter—but it explains why instantaneous sensitivity and accumulated forcing effects are different quantities. The matched-history test measures that distinction directly.

7. A separate limitation: the tracking law

Both the sampled experiment and the existing native KLQR value calculation use:

uₖ = −Kₖ(zₖ − z*ₖ).

At exact tracking, the error is zero and the commanded input is zero. A viscous bubble’s sustained sine-driven response requires persistent nonzero forcing. Therefore this law generally needs a persistent tracking error to generate that forcing. Better B estimation alone cannot remove this structural limitation.

Even with a perfect lifted model, in split-real coordinates the error obeys the following equation. Here M is the two-by-two real representation of μ, bd is the two-by-one input vector, and η = z − z*:

ηₖ₊₁ = (M − bdKₖ)ηₖ − (z*ₖ₊₁ − Mz*ₖ).

The final term is nonzero for a forced reference. Standard nominal-trajectory LQR includes a nominal input in addition to error feedback; see MIT’s LQR and trajectory-stabilization derivation. No nominal-input term was added here. Exact latent tracking need not imply exact echo tracking if ψ is non-injective, which makes the control interpretation harder, not easier.

Can the existing fitted map recover the target input offline?

With the true driver withheld from the calculation, the minimum-residual real input for the assumed one-complex-mode model is:

ûₖ = Re[conj(B̂d(z*ₖ)) · (z*ₖ₊₁ − μz*ₖ)] / |B̂d(z*ₖ)|².
q⊥,ₖ = (z*ₖ₊₁ − μz*ₖ) − B̂d(z*ₖ)ûₖ.

The known driver is used only for scoring. This offline inversion uses the next target sample and is not a causal state estimator or deployed control law. q⊥ measures the residual no real scalar input can explain under this particular fitted model.

8. Observability, controllability and numerical conditioning are different questions

Nothing here proves that echo plus its full history is intrinsically insufficient for control. We have established failure of these particular truncated coordinates, polynomials, input maps and tracking law. We have not measured a global observability rank, found an exact indistinguishable-history counterexample, or proved that no alternate free-trained representation works.

A controllability test of the fitted lifted pair alone can be misleading. For one complex λ = a + iω and a real input vector b in its two-real-coordinate realization,

A = [[a, −ω], [ω, a]],   det[b, Ab] = ω‖b‖².

For ω ≠ 0 and b ≠ 0, that model has full two-state controllability rank. This says nothing about whether its B is the plant’s causal response. Likewise, full regression-design rank does not eliminate bias from an incorrect drift model. A weak one-step response can make input inversion fragile without proving the physical system is uncontrollable over a longer horizon.

Delay-coordinate methods and data-driven controlled Koopman models are established possibilities, but not guarantees for this chosen representation. The original HAVOK paper distinguishes leading delay coordinates from unresolved forcing coordinates; Korda and Mezić’s controlled Koopman work and Arbabi, Korda and Mezić’s sparse-measurement control study provide relevant context. These references are not evidence that our specific free-trained ψ and memoryless B must work, and no alternative method from them was implemented.

10. Recommended next steps, within the existing framework

  1. Retire the present maps as validated causal Bψ estimates. Preserve them as experiment artifacts. They are residual regressions, often measuring forced-history correlation rather than the next-input effect. Do not use fit residual or closed-loop appearance alone as validation.
  2. Use paired perturbations to identify input response. Repeated, matched echo histories followed by zero and ±input continuations allow the existing fitter to target sensitivity instead of mixed drift. Begin with repeated unforced prefixes, then assess histories reached under control. In a laboratory these are repeated preparations, not exact state cloning; reproducibility and echo-history matching must be quantified.
  3. Make zero-input closure a gate before further KLQR tests. Keep U and ψ training unforced. Evaluate ψ after switching input off from driven histories. If zₖ₊₁(0) ≈ μzₖ fails by an amount comparable to or larger than the actual input response, a B-only regression cannot repair that ψ model. The tiny mild sensitivity-fit result is encouraging, but the drift gate still fails.
  4. Continue the requested two-to-four progression with controlled comparisons. Use the same free-training coverage, comparable dictionaries, separate amplitude/time validation bands and fixed test cases. Require gains in autonomous closure and sensitivity predictability, not just Hankel energy. If needed, the existing multi-mode KROM structures can retain more than one eigenfunction; that is a future within-framework option, not something tested here.
  5. Treat nonlinear map capacity as a separate gate. The tiny paired test already leaves 32–131% held-out sensitivity error. More independent local calibration trajectories are justified, but merely repeating longer sines cannot prove a memoryless bilinear map is adequate. Do not assume general B(ξ) has been tested: the current map is affine in one complex ψ.
  6. Only after model validation, revisit persistent-target tracking. A nominal-input or proper tracking formulation would require an explicitly approved controller change. First demand reliable offline target-input reconstruction and low perpendicular residual without supplying the true target driver to the calculation. Then retain KLQR as the feedback part; do not mistake gain tuning for solving the nominal-forcing issue.

Scope conclusion: with these frozen free-trained ψ, fixed μ and B(z)u-only lifted dynamics, accurate general nonlinear control is outside what this particular fitted model presently supports. The observed nonzero zero-input drift cannot be corrected by B alone. This is not a rejection of the whole DynSysLab framework or echo-only control. If closure cannot be obtained with validated free-trained coordinates/eigenfunctions and the existing model structures, stop and seek approval before introducing history-aware drift, input-history augmentation, observers or a different controller.

No such expansion was implemented. Successful nonlinear control remains unresolved; the diagnosis is the completed outcome of this goal.

  • Isolated C++ diagnostic source (no primary source edits). It links existing native DLLs and the unchanged experiment adapter.
  • Full native diagnostic metrics; paired-fit capacity metrics; completed interrupted controls.
  • Mild measurement-only probes and nonlinear measurement-only probes. Their metadata records replay error and the information boundary. Other arrays and native Viewer payloads are retained locally alongside these outputs.
  • Prior experiment report remains unchanged; regression implementation, projection implementation, and native LQR/controller implementation are the audited sources.

Limitations: two target amplitudes/frequencies, one period sampled at 12 phases per target, no measurement noise, no direct scattering, no actuator dynamics, no independent closed-loop confirmation, no proof of injectivity, and no formal nonlinear stability certification. Finite-difference sensitivity is about u = 0 at fixed history, not an exact instantaneous state Jacobian or a global input map. The sampled-to-continuous conversion used by prior controls freezes B over a hold; its error was not separately isolated here.

The final verification record is verification.json: primary-source hashes, targeted tests and rendered-report checks. No large scientific/media assets were committed or published.
