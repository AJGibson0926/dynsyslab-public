DynSysLab · echo-only · 9 October 2026 · isolated native C++ experiment

Do more eigenfunctions improve echo-history control?

Not in this controlled comparison. The strongest result remains one fundamental eigenfunction with the short window on the mild target: 8.50% echo error and 9.58% driver error. Adding modes does not reliably improve either window and does not rescue the nonlinear target. The reasons are partly identifiable: cost-weight redistribution, poor forced-response models for the added modes, free-to-forced history mismatch, and—in aggressive cases—numerical failure or saturation. This is not a proof that every multi-eigenfunction controller must fail.

1. Exactly what changed

Two latent coordinates in every run. The long and short history bases are the previously archived U matrices; no new Hankel SVD was performed. The long window has 8644 echo samples spanning 4.3215 τ (13.018 μs); the short window has 101 spanning 0.05 τ (0.15062 μs). Sensor spacing is 0.0005 τ, control hold 0.01 τ, with τ = 3.012383 μs. The frozen bases store four columns, but only ξ₁ and ξ₂ enter every eigenfunction.

For each window, one degree-five EDMD operator was fitted to the same eight unforced training records over 35–80 τ. Its dictionary contains 21 terms. Three stable, positive-frequency modes were selected, one from each predeclared band [4,8), [8,16), [16,24) rad/τ. Selection minimized the sum of 1- and 4-τ free-trajectory errors over 35–80 τ on six existing validation records. Those records were also used in previous work, so these are reused selection/validation data, not a fresh blind test. All 21 candidates were preserved this time.

We call the selected fundamental, second-frequency and third-frequency candidates ψ1, ψ2 and ψ3. These labels are local to each window; they do not denote latent coordinates. The seven tested subsets were ψ1, ψ2, ψ3, ψ1+ψ2, ψ1+ψ3, ψ2+ψ3, and ψ1+ψ2+ψ3. Negative-frequency conjugates were not double-counted.

This is a new matched mode-bank comparison, not an exact rerun of the earlier degree-one single-mode baseline. Both windows now use the same polynomial degree and training interval. The old models and primary pipeline remain unchanged.

Same model family and controller

zⱼ = ψⱼ(ξ₁, ξ₂),   μⱼ = exp(λⱼh)
zⱼ,ₖ₊₁ − μⱼzⱼ,ₖ ≈ [cⱼ₀ + cⱼ₁ Re(zⱼ,ₖ) + cⱼ₂ Im(zⱼ,ₖ)]uₖ.

Each row of B was fitted using the existing native history-input fitter, on six local sine calibration recordings (records 1–6); two complete waveforms (7–8) were withheld. The target waveform itself was not used to regress B. Mild calibration amplitudes were 0.004, 0.008, 0.016, with 0.025 withheld; nonlinear calibration amplitudes were 0.18, 0.24, 0.36, with 0.42 withheld. Each amplitude has two phases. The mild target is amplitude 0.012 at 0.93 cycles/τ; nonlinear is 0.3 at 0.83 cycles/τ. B sees only measured echo, its history and recorded input. Eigenfunctions see only unforced training data.

The same independently fitted B rows are retained across subsets. They are assembled into the standard conjugate-complete bilinear control-map class with diagonal predictor blocks. This isolates adding feedback eigenfunctions; it does not test a richer cross-mode B regression. Each added mode supplies another output row, not new predictor terms to an existing row.

wⱼ = zⱼ / RMS(zⱼ,target),   Q = I/m,   R = ρ/0.1²,
uₖ = clip[−K(wₖ − wtarget,ₖ), −0.6, 0.6].

The existing continuous-time CARE solver is called each control hold; sampled B is converted using Bᶜⱼ = Bᵈⱼ / [(μⱼ−1)/λⱼ]. This is the prior frozen-map conversion approximation, not a claim of exact sampled-data LQR. The target is projected from its echo; the known target driver is excluded from feedback and used only for scoring. There is no feedforward term. Runs start at r=1, v=0, turn feedback on at 6 τ and end at 60 τ.

The main factorial sweep comprises 2 windows × 2 targets × 7 subsets × 3 penalties (ρ=100,1,0.01) = 84 attempts. Sixteen supplementary single-mode attempts isolate weight redistribution. Total: 93 completed, 7 failed. Errors below use 30–60 τ unless noted; final 50–60 τ metrics are also saved. This is finite-horizon late-time evidence, not proof of indefinite stability.

4. Is it merely weaker weighting of ψ1?

With Q=I/m, adding modes divides the fundamental's cost weight by m. A one-mode controller with penalty mρ has the same fundamental cost/input ratio as an m-mode controller with penalty ρ. The following supplementary cases distinguish dilution from what the extra modes do.

Long mild: ψ1 at ρ=200 and ψ1+ψ2 at ρ=100 both give approximately 73.8% echo error. Most of this apparent worsening relative to ψ1 at ρ=100 is just cost redistribution; it is not convincing evidence that ψ2 independently destroys the response.

Short mild: the weight-matched single gives 11.93% echo and 12.89% driver error, while the pair gives 14.43% and 187.44%. Here the extra mode is doing something genuinely harmful to driver recovery beyond cost dilution. For the triple at ρ=1, even the weight-matched single is much better. The evidence does not support a monotonic “more modes is better” rule.

7. What this does—and does not—establish

  • For these two-coordinate representations, these candidates and these maps, adding eigenfunctions gives no reliable improvement and can materially worsen input recovery.
  • Long-history late free ψ1 is much more accurate than its control performance suggests. The failure is not simply “all eigenfunctions are bad”; the forced-history extension and B interpretation matter.
  • Harmonic-like functions are additional features of the same ξ₁,ξ₂, not additional measurements. They cannot separate two echo histories that already project to identical ξ. A second-frequency function alone can also introduce phase ambiguity.
  • Only three frequency bands, one fixed degree-five dictionary and one late training interval were tested. Other modes, real decay modes, more global training, different weights or a full cross-mode B fit could behave differently.
  • The experiment deliberately held each B row fixed across subsets. It does not answer whether allowing Bⱼ to depend on all selected ψ values improves approximation. That is a separate model-capacity factor, not yet tested.
  • Seven aggressive short-window cases failed in the unchanged CARE implementation (“Riccati solution is not real”). Coordinate normalization did not remove all such failures. Those runs do not establish physical instability; they are recorded as numerical failures, not assigned fabricated tracking scores.
  • Three completed short/nonlinear runs at ρ=0.01 (ψ1, ψ1+ψ2, ψ1+ψ3) also reached elevated CARE residuals, up to 1.42×10⁻⁴. Their near-100% tracking errors are retained transparently, but these are not numerically certified controller solutions. No favorable nonlinear conclusion rests on them.
  • The first unnormalized-cost sweep is retained as v1. The main reported v2 uses the algebraically equivalent normalized formulation. Some saturated nonlinear closed-loop runs are sensitive to floating-point differences. Good mild runs agree closely; numerical equivalence is separately tested.
  • No feedforward was added. Because u=−K error vanishes at zero tracking error, exact sustained tracking of a nonzero-input target is not generally an invariant solution of this controller. This limitation was held fixed across mode counts.

Recommendation: do not promote the multi-mode banks into the primary pipeline. Keep short-window ψ1 as the mild-case reference. Before testing four latent coordinates, the clean next two-coordinate comparison is the same modes with a jointly regressed, conjugate-complete B map versus the fixed-row maps here, retaining causal and held-out validation. That would separate “more feedback coordinates” from “more capacity to model actuation.” If clean forced-response validation still fails, adding more controller modes is not the appropriate fix. No such extension was implemented in this run.
