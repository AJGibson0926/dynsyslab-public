# Capability ledger: Python Viewer, tools/, tools/experiments/, scripts/, case-study programs

Read-only audit, 2026-11-25. Native evidence paths are relative to the repo root.
Abbreviations: WF = workflow/native/src, VN = viewer/native/src, CORE = native/include/dynsyslab/core,
CLI = compute_workbench/native/src.

Context notes
- Python `viewer/` depends on Python packages `archiver.gateway`, `time_series` (missing from the tree),
  `rom`, `estimation`, `postprocessing`, `spectral`. It cannot run on the native-only tree as is.
- No file in viewer/*.py or tools/*.py cites a paper. Side-car code cites only the Colbrook references
  README. Case studies name Korda–Mezić and Doyle (1978) without full references.
- Compile breaks found (details in section 4): `KoopmanModel::eigenfunctions()` (gone), 
  `gradientPolynomialEigenfunction`, `polynomialEigenfunctions()` -> `eigenfunctionSet()`,
  `KoopmanValidationResult` -> `EigenfunctionValidationResult`, `KoopmanSINDyResult::fromCoefficients`
  -> `KoopmanModel::fromPolynomialCoefficients`, `KoopmanErrorStatistics` -> `EigenfunctionErrorStatistics`,
  `trimTimeSeries` -> `cropSamples`; rpe-joint-hdmd-klqe links nonexistent `dynsyslab_estimation`.
