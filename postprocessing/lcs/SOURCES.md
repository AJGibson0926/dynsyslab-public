# LCS suite provenance

- [LCStool](https://github.com/haller-group/LCStool), Haller group: MATLAB computational engine for geodesic LCS extraction.
- [LCS Tool paper](https://arxiv.org/abs/1406.3527): theoretical and numerical reference.
- [lagrangian](https://lagrangian.readthedocs.io/en/stable/): optional Python FTLE package, not vendored.

The `external-lcstool/` directory is an isolated upstream-snapshot location. Preserve the upstream license and README when populated.
