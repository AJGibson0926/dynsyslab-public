# SSM suite provenance

- [SSMtool](https://github.com/haller-group/SSMtool): MATLAB package for parameterization-method computation of two-dimensional SSMs; upstream states GPL/research-use terms.
- [SSMLearn](https://github.com/haller-group/SSMLearn): data-driven nonlinear model reduction via spectral submanifolds.
- [SSMTool documentation](https://ssmtool.mae.sustech.edu.cn/index.html): current project documentation and download information.

`external-ssmtool/` and `external-ssmlearn/` are isolated upstream-snapshot locations. Do not merge their MATLAB source into dynsyslab Python code; retain each project's license and attribution on download.
